# AI Agent 面试训练问题清单

本清单按 `docs/AI_AGENT_INTERVIEW_TRAINING_RULES.md` 的训练路线整理。
这里只保存问题，不保存参考答案、训练进度或答题记录。项目相关问题应结合 Steam Agent 的真实代码、测试、日志和评测证据回答。

## 一、Agent 基础与 Steam Agent 系统地图

1. 什么是 AI Agent？它与普通 LLM 问答应用有什么区别？
2. AI Agent 与固定工作流的本质区别是什么？
3. AI Agent 的基本组成部分有哪些？
4. AI Agent 如何理解用户目标并决定下一步行动？
5. Agent 中的感知、决策、行动、观察分别是什么？
6. 为什么能调用工具还不足以证明一个系统是真正的 Agent？
7. 结合 Steam Agent，说明用户请求从 API 进入到最终返回的完整链路。
8. `AgentState` 保存什么信息？`messages`、`user_id`、`steam_id`、`thread_id` 分别有什么作用？
9. Steam Agent 为什么采用 `agent -> tools -> agent` 的循环？
10. Agent 如何判断继续调用工具还是结束回答？
11. Steam Agent 如何处理匿名用户没有 `steam_id` 的情况？
12. 如何证明 Steam Agent 不是固定工作流，而是真正根据中间结果动态决策？

## 二、Agent Runtime 与核心框架

1. 什么是 ReAct？Thought、Action、Observation 分别是什么？
2. Steam Agent 中的 Agent 节点、工具节点和消息状态如何对应 ReAct 的三个阶段？
3. 工具返回结果后，为什么要重新交给 Agent 节点？
4. 工具返回空结果、错误、超时或无关信息时，ReAct 循环应该如何处理？
5. Agent 为什么需要状态管理？没有状态会出现什么问题？
6. 当前对话状态和跨会话记忆有什么区别？
7. 什么是规划（Planning）？为什么 Agent 不一定要一开始生成完整计划？
8. 动态规划和预先规划各有什么优缺点？
9. 什么时候适合边执行边决策，什么时候适合先生成完整计划？
10. Agent 的执行过程为什么必须有终止条件？
11. 工具调用次数、Token、总耗时等预算分别解决什么问题？
12. Agent 陷入重复调用或无限循环时，运行时应如何保护？
13. `finalize`、`validate`、`repair`、`safe_fallback` 分别解决什么问题？
14. 为什么不能只依赖 LLM 自己判断是否停止？
15. Agent 的自主性和可控性之间有什么矛盾？
16. 如何设计 Agent 的状态、循环和终止机制，使它既灵活又可控？
17. 如何验证 Agent 的规划和执行逻辑确实有效？
18. 信息不足时，Agent 应继续探索、向用户追问，还是降级回答？如何判断？

## 三、工具调用与工具运行时

1. 什么是函数调用（Function Calling）？为什么工具需要结构化 schema？
2. Steam Agent 的工具 schema 应包含哪些字段和约束？
3. LLM 生成的工具参数为什么不能直接信任？如何做参数校验和上下文注入？
4. MCP 是什么？它与普通函数工具有什么区别？
5. 工具契约应如何定义输入、输出、错误码和证据字段？
6. 什么是幂等性？Steam Agent 中哪些工具需要幂等设计？
7. 工具调用失败时，什么时候应该重试，什么时候不应该重试？
8. 如何设计指数退避、最大重试次数和重试条件？
9. 什么是熔断？工具熔断与 Agent 降级如何配合？
10. 多个工具调用什么时候可以并发，什么时候必须串行？
11. 如何防止并发工具调用产生竞态条件或重复写入？
12. 工具授权应如何实现最小权限？
13. 如何防止模型调用未授权工具或篡改用户上下文参数？
14. 工具超时、取消和 deadline 传播应如何设计？
15. 工具返回空结果、部分结果和错误结果时，统一结果协议应如何设计？
16. 如何观测每次工具调用的名称、参数、耗时、状态和调用原因？

## 四、RAG

1. Steam Agent 为什么需要 RAG？它解决什么问题？
2. RAG 的数据摄取流程包括哪些步骤？
3. 文档或游戏数据为什么需要 chunking？chunk 大小和 overlap 如何选择？
4. Embedding 的作用是什么？如何选择 embedding 模型？
5. BM25 与向量检索各自擅长什么场景？
6. 什么是混合检索？为什么需要结合 BM25 和向量检索？
7. 什么是 RRF？它如何融合多个检索结果？
8. reranking 解决什么问题？它与初始召回有什么区别？
9. Steam Agent 的 `rag_search_similar_games` 如何处理中文查询和标签过滤？
10. 如何评价 RAG 的 Recall@K、MRR、nDCG 和 Precision？
11. 如何构造 RAG 的 query、正例、负例和 hard negative 测试集？
12. 什么是 ablation experiment？如何验证混合检索、rerank 或过滤器的收益？
13. RAG 检索到了相关内容，为什么最终回答仍可能不准确？
14. 如何避免 RAG 返回重复、过时或互相矛盾的证据？
15. 如何处理知识库更新、embedding 版本变化和索引重建？

## 五、Memory

1. Working memory、session memory 和 long-term memory 有什么区别？
2. 当前 `messages` 状态与跨会话用户记忆分别承担什么职责？
3. 什么信息应该写入长期记忆，什么信息不应该写入？
4. `save_user_insight` 的写入策略应如何设计？
5. 用户撤回或修改偏好时，记忆如何更新和删除？
6. 历史对话记忆与结构化用户画像有什么区别？
7. `recall_user_memory` 应在什么场景下调用？
8. 长期记忆的生命周期如何管理？是否需要过期、合并和压缩？
9. 多条记忆发生冲突时，如何判断哪条更可信？
10. 如何避免把模型猜测误写成用户事实？
11. 如何评价记忆的 precision、recall 和 contradiction rate？
12. 记忆系统如何保护隐私、支持删除请求和控制访问权限？

7. 如何识别和隔离不可信指令？
8. 如何应用 least privilege 原则保护工具和用户数据？
9. 工具返回恶意内容时，Agent 应如何处理？
10. 何时应该追问用户，何时应该拒绝，何时应该安全降级？
11. 如何验证安全策略没有误伤正常请求？
