# Steam Agent 待实现规划

本目录是当前项目的实施规划，不是代码实现。它把已经发现的风险、技术债和后续建设拆成可执行任务，便于后续逐项开发、测试和验收。

## 阅读顺序

1. [总清单](00_MASTER_TODO.md)：查看全部任务、优先级、依赖和验收口径。
2. [账号与数据安全](01_SECURITY_IDENTITY.md)：先解决用户身份、授权和数据隔离。
3. [会话、记忆与持久化](02_SESSION_MEMORY.md)：保证多轮对话和长期记忆不会丢失或串线。
4. [Agent 运行时与安全策略](03_AGENT_RUNTIME.md)：整理 Agent 循环、工具预算和安全检查。
5. [RAG 与数据管线](04_RAG_DATA_PIPELINE.md)：保证游戏知识库可重建、可追溯、可验证。
6. [API、前端与部署](05_API_DEPLOYMENT.md)：明确对外服务和生产运行边界。
7. [测试、评测与可观测性](06_TEST_EVALUATION.md)：建立改动后的质量证明。
8. [文档与运维](07_DOCUMENTATION_OPERATIONS.md)：统一项目说明和日常操作手册。

## 规划原则

- 先解决用户数据泄露、串话和误删风险，再增加推荐能力。
- 每个功能都要有确定的验收标准和对应测试。
- 以当前代码为准，旧文档中的“已完成”不能自动视为当前实现状态。
- 对外部服务、模型输出和本地数据都保留可追踪的版本信息。
- 任何涉及真实用户数据的改动，都必须包含迁移、回滚和失败恢复方案。

## 状态标记

- `[ ]` 尚未开始
- `[~]` 进行中或部分完成
- `[x]` 已完成并通过验收
- `P0` 上线前必须处理
- `P1` 近期应处理
- `P2` 优化和长期建设
